## 🛠 Используемые компоненты

* **Elasticsearch** — хранение и поиск данных.
* **Logstash** — сбор и обработка логов (TCP JSON, Syslog).
* **Kibana** — визуализация и построение дашбордов.
* **Filebeat** — доставка логов Docker-контейнеров.
